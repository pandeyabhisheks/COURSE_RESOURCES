# BME 302 and BNC 501 course site

Static site for GitHub Pages. No build step is needed.

## Publish (about 5 minutes)
1. Sign in to github.com and click **New repository**. Name it, for example, `course-resources`. Choose **Public**.
2. On the new repository page click **uploading an existing file**. Drag in the contents of this folder (index.html, hydraulic-machines-simulator.html, .nojekyll and the whole `files` folder). Click **Commit changes**.
3. Go to **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main** and folder to **/ (root)**. Click **Save**.
4. After a minute your site is at `https://<your-username>.github.io/course-resources/`.

## Edit later
Open a file in the repository, click the pencil icon, change it and commit. Replace a PDF by uploading a new file with the same name into `files`.

Note: a public repository makes every file public. Check your institution's rules on hosting course material before publishing.
